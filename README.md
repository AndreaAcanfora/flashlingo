# flashlingo

A static, spaced-repetition **flashcard trainer** for language learning — English
(CEFR-leveled), Spanish, irregular verbs, phrasal verbs and world capitals, all in
one app. No backend, no build step to run it: it's plain HTML + ES modules, so it
hosts for free on GitHub Pages.

> Built-in pronunciation (Web Speech API), typing-check with typo forgiveness,
> Leitner spaced repetition, an adaptive-difficulty mode for the 3000-word deck,
> an in-app editor, and flags for the capitals quiz.

This is a ground-up rewrite that consolidates six old PHP mini-apps into a single
clean, inspectable project.

| Deck | Cards | Notes |

| Geography · World capitals | 171 | country → capital, with flags & continent filter |

## Features

- **Spaced repetition** — a Leitner 5-box scheduler shows the cards you miss more
  often and spaces out the ones you know.
- **Two study modes** — self-grade (flip and rate yourself) or **typing-check**,
  which accepts any valid answer or synonym, is accent/case-insensitive, handles
  comma-joined verb forms, and forgives small typos.
- **CEFR levels & adaptive mode** — for *English · 3000*, filter by level (A1–C2)
  or let **Adaptive** mode start at your level and move up/down based on how you do.
- **Pronunciation** — tap 🔊 (or press `S`) to hear the word via the browser's
  speech synthesis, in the right language per deck. No audio files to host.
- **Flags** — the capitals deck shows each country's flag (static SVGs).
- **In-app editor** — add, edit or remove cards (meanings, synonyms, examples,
  level). Edits are saved in your browser and can be **exported as commit-ready
  deck JSON**.
- **Your data stays yours** — progress lives in `localStorage` with export/import.
- **Dark mode, responsive, full keyboard control, screen-reader friendly.**

### Keyboard

`Space` reveal / next · `1` didn't know · `2` knew it · `Enter` check typed answer ·
`S` speak · `Esc` end session.

## Run locally

It's a static site — any static server works:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

(Pronunciation needs a modern browser; on iOS Safari the first tap unlocks audio.)

## Data & build pipeline

Deck files in `data/` are **generated** from the raw wordlists in `build/raw/` and
validated. You only need this if you change the data.

```bash
cd build
npm ci
npm run build      # fetch CEFR sources → convert → manifest → validate
npm test           # schema + semantic validation (the CI gate)
```

Card shape (`data/<deck>.json`):

```json
{ "front": "accompany", "back": ["accompagnare"], "level": "B1",
  "meanings": ["accompagnare","scortare"], "synonyms": ["escort"],
  "example": "I'll accompany you to the station." }
```

`back` is the tight set of **gradeable** answers; `meanings` is richer display text
shown on reveal (falls back to `back` when absent). See [`build/README.md`](build/README.md)
for the full pipeline, the raw→deck mapping, and data-model details.

## CEFR levels (data sources)

The A1–C2 level on each English word is **derived** from the open
[CEFR-J](https://cefr-j.org/) and Octanove vocabulary profiles (CC BY-SA 4.0). Only
the derived level label ships here; the source CSVs are fetched at build time and
not redistributed. See [`NOTICE`](NOTICE). *(Attribution, not legal advice.)*

## Optional: AI enrichment

You can auto-fill `meanings`, `synonyms` and `example` for the English decks with
your **own** Anthropic API key — nothing calls a paid API unless you run this:

```bash
cd build
cp .env.example .env         # add your ANTHROPIC_API_KEY (and verify the model id)
npm run enrich:dry           # prints scope + token estimate, no API calls
npm run enrich               # writes data/english-3000.enriched.json (a sidecar)
npm run enrich:report        # review the output, flags suspicious rows
# review, then promote the sidecar over data/english-3000.json and run `npm test`
```

The run is resumable and crash-safe, and never overwrites answers you've edited.

## Deploy to GitHub Pages

Push to GitHub, then enable **Settings → Pages → Deploy from branch** (`main`, root).
The app uses only relative paths and ships a `.nojekyll`, so it works at a project
subpath out of the box.
